## 4. Method and rules

### 4.1 Wiki to game match

- Card: wiki picture name = file name in column `ImgCard`. Skin: wiki picture name = `IconId` of the box item (`ItemList.txt`, class `IBGiftAuto`, `ExtParam1` = box id) whose box (`ItemBoxInfo.txt`) holds the skin. All 197 wiki dresses matched; 0 wiki dresses have no game row.
- 8 wiki dresses match 2 card rows each, because level 4 and level 5 of outfit 17 ("Party Dress") share one picture: Party Dress (UR) – Irene, Party Dress (UR) – Moon, Party Dress (UR) – Shi Wuyou, Party Dress (UR) – Juno, Party Dress (UR) – Yuki, Party Dress (UR) – Lida, Party Dress (UR) – Grainne, Party Dress (UR) – Cornelia.
- 121 game dresses have no wiki entry (column "Wiki" = `—` in section 6). The wiki page says more content is coming. `[INFER]` the wiki stops at the events of mid 2022 (its newest entries are the "Winter Outfit" cards).

### 4.2 Ways to get a dress

- **Banner.** `gacha.txt` rows with `Type` 1 are character pools; rows with the same `ID` are segments in file order; column `Pool` names the pool file. The server opens the segment that `gacha-rotation.json` selects (`server/src/SssjServer.Game/Config/GachaTable.cs:361-365`, `GachaRotation.cs:81-86`). A card counts when its pool row has `Rate` above 0.
  - Build 5 (`server/setting.build5/gacha.txt`, `server/setting.build5/gacha-rotation.json` sha1 `f34b7b1c2ca3`): 25 character pools, 41 segments, 25 segments in the rotation, 25 open on 2026-11-14. Cards in any segment: 124; in a rotation segment: 124; open on 2026-11-14: 124.
  - Build 179 (`server/setting/gacha.txt`, `server/setting/gacha-rotation.json` sha1 `98f6c2b80b21`): 42 character pools, 98 segments, 72 segments in the rotation, 42 open on 2026-11-14. Cards in any segment: 181; in a rotation segment: 181; open on 2026-11-14: 163.
  - Segments outside the rotation are the old periods of the standard pool (ID 1), see appendix A. No card is only in such a segment (the two card counts above are equal).
  - Build 179 pool 43 ("Boss to Café") has 31 periods; the rotation runs them one after another, 15 days each, from 2026-11-01. A card that is only in pool 43 is open only in its periods.
  - Pool files that no `Type` 1 row uses (for example `card_52_ZH.txt` in build 5) cannot be reached. Status: "pool file only".
- **Other sources.** Every flat table was searched for the item reference (dash form `g-d-p-l[-n]`, and the comma form in `PurchaseIBShop.txt`, `PurchaseIB.txt`, `BattlePassIB.txt`). A hit counts only in a reward column:

## 5. Reading the main table

- **★**: `Level` of the card (5 = the level-5 form). Skins show their `L`.
- **Wiki**: wiki name (link) and wiki rarity (UR, SR, R, C, Dress-up). `—` = no wiki entry.
- **Build 5 / Build 179**: how to get it. Pool files and tables are in `server/setting.build5/` and `server/setting/`. "UP in N" = featured (`UpFlag` 1) in banner N. Banner numbers: appendix A.
- **v0.1.3**: how to get it in GCG-Offline v0.1.3. Files are inside its server payload (section 4.4).
- **Assets**: `ok`, or what is missing in our OBB and `assets/Bundles`. A `v0.1.3:` note is added when a bundle is missing by name there.
